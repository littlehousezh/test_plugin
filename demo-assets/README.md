# TestCompass Demo Assets

These demo assets show the TestCompass student workflow without exposing a real student ID or Amplify token.

## Files

- `01-marketplace-install.png`: install TestCompass from JetBrains Marketplace.
- `02-first-time-setup-redacted.png`: first-time setup dialog with redacted credentials.
- `03-run-tests-with-coverage.png`: run `MarsRoverTest` with coverage.
- `04-testcompass-hotspots.png`: review coverage hotspots in the TestCompass tool window.
- `05-ai-recommendations.png`: generate AI test recommendations.
- `testcompass-demo.gif`: animated walkthrough using the same redacted frames.

The actual token and student ID are not present in these files.
